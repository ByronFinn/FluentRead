# 评论助手

评论助手在划词卡片中提供「评论」页签：选中网页文字（含图片）后点击页签，按你在设置中定义的风格指令生成若干条可直接粘贴到社交平台的候选评论。

## 使用

1. 设置 → 专项翻译 → 评论助手，开启「启用评论助手」。
2. 选择评论服务与模型（默认跟随当前 AI 服务），设置评论条数（1–5）。
3. 在网页中选中文字，点页签条中的「评论」；面板自动开始生成。
4. 每条候选右下角「复制这条」，或底部「复制全部」；「重新生成」会取消上一条在途请求后再发。

入口规则：评论入口不依赖划词翻译或读懂助手的开关，仅开启评论助手时选中文字也会出现指示条；选区语言与目标语言相同（包括中文对中文）时评论入口照常出现。

## 提示词模型

与翻译卡片的提示词体系一致：你只编辑「风格指令」段，安全规则、选区包装与输出契约由代码固定，用户内容不能覆盖它们。留空使用默认风格；`{{count}}` 占位符会替换为评论条数。

## 结构契约

评论结果通过模型工具调用（`submit_comments`）返回，参数按 zod 严格校验，与阅读/写作助手使用同一套结构化输出机制；模型未按契约提交时面板给出可重试的错误。

## 边界

- 评论结果只用于即时复制，不写入学习记录，不做本机持久化。
- 每次模型调用与其他 AI 功能一样计入「模型用量」统计（与翻译卡片归入同一用途分类），用于查看耗时与 Token 消耗。
- 风格指令属于用户配置，会随配置导出、备份与历史快照保存，处理方式与翻译卡片提示词相同。
- 选区图片经画布降采样为 JPEG（透明像素先铺白底）后随请求发送，上限 4 张、单边 1024px；表情图标自动过滤，跨域受限的图片自动跳过，只按文字生成。
- 站点禁用名单、全局开关、评论配置变更与卡片关闭都会即时取消在途请求，包括尚未完成的图片捕获。
- 修改评论配置只失效评论面板的现有结果，需要点「重新生成」才使用新配置；不会影响翻译卡片的回答缓存。
